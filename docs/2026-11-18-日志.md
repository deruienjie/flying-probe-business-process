## 一、墨刀 MCP 接入（半天，结论：走 OAuth）

| 方式 | 结果 | 结论 |
|---|---|---|
| 令牌设置里的个人空间令牌（`modao_` + 43 位） | `401 MCP API Key 无效` | 新旧两个 key 都被拒，**这条路走不通** |
| 同样的令牌换 5 种请求头写法 | 全 401 | 不是头名问题（`modao-token` 是官方写法） |
| OAuth（动态注册 + 本机回调 + PKCE） | ✅ 通过，19 个工具 | **采用这条** |

关键证据：把 OAuth 换来的 access token 放到 `modao-token` 头里也能通过，说明网关认 `modao_` 令牌，只是**令牌设置里签发的那批没进网关的校验库**——墨刀侧的数据问题，客户端无法绕过。

踩的两个坑（都是自己的）：

1. 换 token 时漏了 `resource` 参数 → `400 invalid_grant: resource does not match`
2. 回调服务用了单线程 `TCPServer`，`shutdown()` 被浏览器 keep-alive 卡死 → 进程挂住，白让用户点了两次授权

最终方案：OAuth access token（1 小时）+ refresh token 刷新脚本。

### 今天定下的三个关键决策

**1. 列表（表格）是主视图，详情是二级页**
一开始让"点树里的微环节"直接跳详情页，用户看到的是卡片布局，以为做错了。
改成：点任何微环节都停在列表，只有点抽屉里的「查看完整详情」才进详情。

**2. 用"三个视觉通道"分配层级，不只靠透明度**
- 段 → 彩色字母块 + 大字号（主体）
- 微环节 → 小字 + 弱色 + 缩进（背景）
- 七属性 → 点击原地/抽屉展开（焦点）
另外加：密度三挡、段可折叠、悬停时其余变暗。

**3. 空白用"判断内容"填，不用留白凑**
详情页补上：上下游链、本段位置、上游/下游交接、判定与风险。
段视图补上：涉及角色、系统落位、AI 化分布（比例条）、线上化落地建议（先做/再做/最后动）。
这些块本身就是面试要讲的东西，不是装饰。
