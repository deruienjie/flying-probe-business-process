# 设计规范（v2）

从 [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) 的 checklist 里挑出**适用于信息密集型页面**的部分，落地到本项目。

## 一、设计令牌

```css
/* 字阶：只保留 6 档 */
--t-xs: 12px;  --t-sm: 13px;  --t-md: 14px;
--t-lg: 16px;  --t-xl: 20px;  --t-2xl: 26px;

/* 颜色：一个主色 + 四档文字色 */
--ink: #0f172a;    /* 标题 */
--ink2: #334155;   /* 正文 */
--muted: #64748b;  /* 次要（4.5:1） */
--faint: #94a3b8;  /* 仅用于标签，不用于正文 */
--accent: #2563eb;
--line: #e2e8f0;   --line2: #eef2f8;

/* 圆角：只 3 档 */
--r-sm: 6px;  --r-md: 10px;  --r-lg: 14px;
```

**阶段色**（语义色，允许彩色，但避免紫）：

| 阶段 | 色值 |
|---|---|
| 市场与销售 | `#2563eb` |
| 订单评审与立项 | `#0891b2` |
| 设计与 BOM | `#0f766e`（原 `#7c3aed` 紫，已替换） |
| 计划与采购 | `#d97706` |
| 装配与调试 | `#db2777` |
| 测试与验收 | `#0d9488` |
| 现场交付 | `#4d7c0f` |
| 回款与售后 | `#b45309` |

## 二、质量线（已落地）

| # | 规则 | 实现 |
|---|---|---|
| 1 | 一套字阶 | 6 档，不再出现 10.5 / 11.5 |
| 2 | 一套圆角 | 6 / 10 / 14 |
| 3 | 一种卡片 | 白底 + 1px 边 + 悬停上浮 2px |
| 4 | 一种按钮 | 实心（主）/ 描边（次） |
| 5 | 对比度 ≥ 4.5:1 | 正文 `#334155`，次要 `#64748b` |
| 6 | 焦点环可见 | `:focus-visible { outline: 2px solid #2563eb }` |
| 7 | 减少动效 | `prefers-reduced-motion` 下关闭过渡 |
| 8 | 点击区 | 表格行 38px、树节点 ≥ 30px |
| 9 | 标题层级 | 真 `h1` / `h2`，不跳级 |
| 10 | 内容不留半空 | 每屏内容 ≥ 60% 高度，不足则补判断块 |
| 11 | 文案说人话 | 标题写名词、按钮"动词+对象"、不用套话 |
| 12 | 截断有补偿 | 表格单元格 `title` 悬停看全文 |

## 三、不适用的规则（官网专用，本项目不采纳）

- 一屏一 section、首屏 hero、每个 section 1~2 屏高
- 真实照片 / 产品渲染图 / 图形化 hero
- 入场动画、悬停 1.02 缩放、2.5–4s 卡片循环
- 全站 44px 触控目标（桌面工具类页面不需要）

## 四、检查方法

改完样式后自检：

1. 字号有没有出现第 7 种？
2. 圆角有没有出现第 4 种？
3. 一屏截图，内容占高是否 < 60%？
4. Tab 键走一遍，焦点环是否可见？
5. 缩到 1024 宽，有没有横向滚动条？
